Retention & the GPS myth

On-device retention: up to ~14 days (WHOOP support docs). Catch-up can take ~1 hour.
Durable store: type-47 historical record in a page-slot ring buffer (bounds via GET_DATA_RANGE).
Removal: the acknowledged/trim boundary advances only on HISTORICAL_DATA_RESULT (cmd 23) after a durable local commit.
GPS: there is none. WHOOP 5/MG has no GNSS chip; API distance/altitude is phone-derived.
